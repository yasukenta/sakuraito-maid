# 桜色メイドは、幼馴染で許嫁でした。

青春ラブコメディ短編小説（日本語・英語／全7章）。
学校課題「複数のAIを使った作品制作」として制作しました。

## 公開ページ

`index.html` が作品本体です。GitHub Pages を有効にすると公開されます。

## 内容

- **本編**（全7章・視点切り替え式）を日英ワンページに統合
- 右上のボタンで **日本語 / English** を切り替え（読んでいる位置を保持）
- 表紙の**目次から各章へジャンプ**
- ページ末尾に **後日談のAI執筆デモ**（3本・日英対応、オフラインで動作）
- 桜の花びらの演出、印刷（PDF保存）用レイアウト対応

## 制作の流れ（複数AIの連携）

1. 画像生成AIでキャラクターデザインを作成
2. 画像を読み取り、設定をテキスト化
3. 文章生成AIで小説を執筆
4. 英語版へ翻訳・Webサイト化
